# WOBI — תיעוד מוצרי

WOBI הוא כלי עזר ל**ליגת החלומות (Dream Team / Sport5)**: לעזור לבחור חילופים והרכבים עם נתונים מקומיים (מחיר, נקודות, לוח משחקים, תמורה לכסף).

## למי זה מיועד
שחקן פנטזי שמנהל קבוצה אחת, מעדיף מסך עבודה צפוף בעברית, ורוצה לראות במהירות קושי יריבות ותמורה למחיר לפני חילופים (עד 3 לשבוע במשחק).

## מסכים

### הקבוצה שלי (`/squad`)
- מגרש לפי עמדות (שוער למעלה → התקפה למטה).
- ספסל: 4 משבצות קבועות (שוער → הגנה → קישור → התקפה); ריק = לחיצה מסננת לפי עמדה.
- **גרירה** מהטבלה להרכב/ספסל.
- **X** מסיר שחקן; **לחיצה על כרטיס/שם** פותחת פירוט נקודות (`statsData`).
- תקציב בפינה: הוצאה / **120** / פנוי (כולל ספסל).
- סיכום **חילופים עד כה** מול ההרכב השמור (יוצאים / נכנסים); מתאפס אחרי שמירה.
- טבלת שחקנים (~410): מיון לפי כותרות, חיפוש, עמדות, קבוצות, טווח מחיר, רמזור יריבה קרובה.
- מדדים: נקודות עונה (מחזור בסוגריים), **vlfm**, **עשירון נקודות**.

### מעקב (`/watchlist`)
רשימות מעקב קבוע / למחזור — לשימוש בהמשך (לא משולב עדיין במסך אפשרויות קבוצה).

### מחזור (`/gameweek`)
לוח משחקים לפי מחזור (ניווט 4–26), רמזור יריבות, ומבט על שחקני ההרכב+מעקב.

### הצעות חילופים (`/transfers`)
הצעות היוריסטיות עד 3 חילופים מול ההרכב הנוכחי.

### אפשרויות קבוצה (מסך חדש)
מציג כמה הרכבים מוצעים לפי אסטרטגיות שונות (נקודות / vlfm / לוח קל / מאוזן) בתוך מגבלות התקציב והעמדות. **בלי מעקב בשלב זה.**

## מושגי ליבה
| מושג | משמעות |
|---|---|
| תקציב | 120 מיליון ל־15 שחקנים (XI+ספסל) |
| רמזור | קושי יריבה: אדום קשה, צהוב בינוני, ירוק קל |
| vlfm | נקודות עונה ÷ מחיר |
| עשירון | מיקום יחסי בפול לפי נקודות (עליון…תחתון) |
| מומנטום | מתוכנן ממחזור 7 — אחרי צבירת היסטוריית מחזורים |

## זרימת עבודה טיפוסית
1. עדכון `players.json` → `bun run db:import-players`
2. לוח משחקים מעודכן ב־DB
3. בניית/עדכון קבוצה ב־`/squad`
4. השוואת אפשרויות במסך החדש / הצעות חילופים
5. שמירה לפני הדדליין במשחק המקורי

## מה עדיין לא במוצר
- מומנטום 3 מחזורים (צבירה פעילה; תצוגה ממחזור 7)
- שילוב watchlist באפשרויות קבוצה
- סריקת Dream Team חיה (הוחלף חלקית ב־ONE ללוח)

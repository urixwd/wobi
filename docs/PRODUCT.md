# WOBI — תיעוד מוצרי

WOBI הוא כלי עזר ל**ליגת החלומות (Dream Team / Sport5)**: לבחור חילופים והרכבים עם נתונים מקומיים (מחיר, נקודות, לוח משחקים, תמורה לכסף).

## מקור נתוני שחקנים (חשוב)

### מה קרה ל־`players.json`?
הקובץ **נמחק מהריפו**. הוא היה dump חד־פעמי של Sport5 לפני מחזור 4. מעכשיו:
- האפליקציה קוראת שחקנים **רק מה־DB**
- dump JSON של Sport5 הוא **קלט זמני** לייבוא מחזור (`--gw=N`), לא קובץ קבוע בפרויקט
- גיבוי שמתחייב לגיט הוא **`db/dumps/latest.sql`** (pg_dump של כל ה־WOBI), לא JSON של שחקנים

- **מקור האמת הוא PostgreSQL**, לא קובץ בריפו.
- כל מחזור מגיע כ־dump מ־Sport5 → מיובא ל־DB עם מספר מחזור (`--gw=N`).
- ב־DB נשמר **snapshot לכל מחזור** (`player_snapshots`) + טבלת `players` כתצוגה חיה של המחזור האחרון שיובא.
- כרגע במערכת: **מחזור 4** בלבד.
- **זרימה עתידית:** בעוד כמה ימים אביא קובץ חדש ואבקש לייבא אותו כ־**מחזור 5**, ואז 6… עד סוף העונה. אין צורך (ואסור) להשאיר `players.json` קבוע בגיט.

שחקן פנטזי שמנהל קבוצה אחת, מסך עברי צפוף, עד 3 חילופים לשבוע.

## מסכים

### הקבוצה שלי (`/squad`)
מגרש, ספסל, טבלה, פילטרים (יריבה / לוח 5 / קבוצות / מחיר / עמדות), מגבלות (120מ, מקס׳ 2 לקבוצה), staged מ־options/סקיצות, משחקי מחזור למטה.

**לוח (5):** ממוצע קושי 5 משחקים (ירוק=1, צהוב=2, אדום=3) → קל ≤1.5 · בינוני ≤2.25 · קשה מעל.

### סקיצות / אפשרויות / מחזור
כמפורט קודם: חילופים מול השמור, staged ב־URL, הרכב סופי ב־`final_squads`, תצוגת כרטיסים משותפת (`CompactPlayerCard`).

## זרימת עדכון מחזור (חוזרת)
1. Uri מביא dump **JSON מ־Sport5** (לא לשים בגיט; למשל `./incoming/players-gw5.json`).
2. `bun run db:import-players -- --gw=5 ./incoming/players-gw5.json`  
   → מעדכן `players` (חי) + `player_snapshots` למחזור 5 + `player_round_stats`.
3. (אופציונלי) `bun run db:export-players -- --gw=5` — לבנות JSON בחזרה מ־`player_snapshots` אם צריך.
4. `bun run db:dump` → מרענן `db/dumps/latest.sql` (גיבוי Postgres לגיט).
5. לבדוק `/squad`, לעדכן הרכב, לשמור **הרכב סופי** ב־`/gameweek?gw=5` בדדליין.
6. שני commits נפרדים כשצריך: **קוד**, ואז **דאטהבייס** (`db/dumps/latest.sql`).
